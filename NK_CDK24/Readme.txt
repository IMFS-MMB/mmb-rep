Gas_TANK replication

+ last change: August 13, 2024

+ 4 shocks in the model:
eta tfp (ηTFP) : TFP Shock
eta pEf (ηPFX) : Global energy price shock
eta muz (ηM)   : Price Markup Z Shock
eta R (ηM)     : Monetary Policy Shock

+ Original and replicated IRFs are located in the corresponging folders.  

+ Literature:
- Chan, J., Diz, S., & Kanngiesser, D., 2024. Energy prices and household heterogeneity: Monetary policy in a gas-tank. Journal of Monetary Economics, 103620.

+ Findings: The code did not require any major revision to match the IRFs. The main file is Gas_TANK.mod in the folder NK_CDK24_rep.
The macroprocessor of Dynare requires Dynare 4.6 or higher. The model was run with Dynare 5.5 by the authors.
You can run the .m files for the corresponding shocks in the folder NK_CDK24_rep.
